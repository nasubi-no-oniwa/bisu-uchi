# ビス打ち職人

1本目と2本目を好きな間隔で打つ。あとはその間隔のまま、ひたすらビスを打ち続ける。0.05秒ずれたら曲がって終わり。

遊ぶ：https://nasubi-no-oniwa.github.io/bisu-uchi/

- `index.html` … ゲーム本体（1つのファイル）
- `database.rules.bisu.json` … ランキングのルール。GitHub に上げると自動で ft-green の `bisu` に反映（ほかのゲームのルールはそのまま）。リポジトリの Secrets に `FT_GREEN_SERVICE_ACCOUNT` が必要
- `test/rules-test.mjs` … ルールの試験（GitHub の上で試し用のデータベースを立てて試す）

## しくみ
- 1本目と2本目の間隔（0.4〜3秒）が基準。3本目からは「1つ前のビスからの間隔」と基準をくらべ、0.05秒より大きくずれたら曲がって終わり。打たずに0.05秒すぎても終わり
- 1本目を打った瞬間にサーバーの時刻を `bisu/runs/人` に書く。記録は、その時刻から「(本数−1)×間隔」の時間が実際にたっていないと載らない
- 称号：見習い → 半人前（10本）→ 一人前（25本）→ 職人（50本）→ 腕利き（100本）→ 親方（200本）→ 棟梁（400本）→ 名人（700本）→ 人間メトロノーム（1000本）
- 隠し結末：1本目を打つ前に「打つ」ボタンを横にずらすと「定規を使う」が出る。押すと差し金で測ってまっすぐ打つ＝クリア。人数は `bisu/ruler` に1人1つ、ランキングの一番上に出る
- 消したい記録は、Firebase の `bisu/hidden/人のID` に `true` を入れるとランキングに出なくなる
- Xに投稿：文は「ビスを〇本打てた。〇秒間隔・称号…」。リンクは結果ごとのページ `s/本数.html`（0〜300本。301本からは `s/300p.html`・`s/400p.html`…の「〇本以上」、定規は `s/ruler.html`）で、そのページの画像 `s/〇.jpg` がリンクに出る。人が開くとゲームへ移る。日本語以外で遊んだ人は英語の画像 `s/en/` を使う
- 機械判定：30本続けて誤差が0.003秒以内なら「正確すぎる」で終わり、記録しない
- ランキングは上位100人だけ読む。今日の分は `ds`（日×1000000＋本数）の順で、その日の範囲の上位100人を読む（`ds` のない前のページの記録も書けるが、今日の表には出ない）
- 打ちはじめの時刻：失敗したら少し待って何回かやりなおす。「短すぎる・長すぎる」でやりなおした直後（20秒以内）の1本目は、そのときの時刻を使いまわす（前は2秒以内に打ちなおすとサーバーにはじかれ、その回が記録されなかった）
- 記録を手で入れる：`tools/manual-records.json` に書いて GitHub に上げると、管理者としてランキングに入る（`.github/workflows/manual-records.yml`）
